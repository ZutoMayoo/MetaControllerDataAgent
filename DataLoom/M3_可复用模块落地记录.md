# M3 可复用模块落地记录

日期：2026-09-22  
分支：`feat/production-evidence-gate`

## 结论

已将当前确认可复用的架构与组件接入 DataLoom：

1. DataAgent 风格的 Capability Registry、Action Router、权限、Guard、幂等和投影接口；
2. Project Understanding → SQL 的版本化证据交接协议；
3. 受信 `SKILL.md` 的 allowlist 发现、激活和 SHA-256 审计；
4. 统一的工作区路径与 symlink 越界保护；
5. 搜索/工具输出的条数、字符数预算和显式截断记录；
6. SignalPilot dbt scanner/validator 的固定版本 subprocess 适配；
7. DataAgent BIRD Suite 的固定版本 subprocess 适配与 dry-run 接口；
8. Code-aware、Spider2-DBT、BIRD 三类 Benchmark 的统一路由和编排入口。

外部源码未复制进 P12。适配器在每次探测时记录外部 Git revision、许可证和被调用文件的 SHA-256；revision 与钉扎值不一致时 fail closed。

## 路由

| Benchmark | 能力 | 实际实现 |
| --- | --- | --- |
| Code-aware | 项目/代码理解 | DataLoom Native Qwen + EvidencePackage 0.2 |
| Spider2-DBT | dbt 项目理解 | SignalPilot `scan_project.py` / `validate_project.py` |
| BIRD | NL2SQL | DataAgent BIRD Suite 统一模块入口 |

统一入口：

```powershell
python DataLoom/runtime/orchestrator.py catalog
python DataLoom/runtime/orchestrator.py probe --benchmark spider2-dbt
python DataLoom/runtime/orchestrator.py probe --benchmark bird --import-check
python DataLoom/runtime/orchestrator.py scan-dbt --project <dbt-project>
python DataLoom/runtime/orchestrator.py validate-dbt --project <dbt-project>
```

## 明确保留的边界

- SignalPilot 可复用的是成熟的 dbt 理解路径，不被包装成通用代码理解器；
- DataAgent 可复用的是 BIRD/NL2SQL 与 Agent runtime 架构，不被包装成通用业务规则调用链分析器；
- BIRD 的 Gold 只允许宿主机在推理结束后评测；
- 外部组件依赖未满足时返回明确探测失败，不静默回退到另一模型或另一实现。
